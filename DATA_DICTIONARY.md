# Data Dictionary

`housing_data.csv` — 2,010 rows × 13 columns (synthetic, generated by `src/generate_dataset.py`, seed 42).

| Column | Type | Description |
|---|---|---|
| `area_sqft` | numeric | Built-up area in square feet |
| `bedrooms` | numeric | Number of bedrooms (1–5) |
| `bathrooms` | numeric | Number of bathrooms (1–6) |
| `age_years` | numeric | Age of the building in years (~3% missing) |
| `floor` | numeric | Floor on which the flat is located |
| `total_floors` | numeric | Total floors in the building |
| `parking_spaces` | numeric | Number of parking spaces (0–2) |
| `furnishing` | categorical | Unfurnished / Semi-furnished / Furnished (~2% missing) |
| `locality_type` | categorical | Prime / Mid-range / Suburban |
| `distance_to_center_km` | numeric | Distance to the city centre in km (~2% missing) |
| `has_lift` | binary | 1 if the building has a lift |
| `has_security` | binary | 1 if the society has security |
| **`price_lakhs`** | **target** | Sale price in Indian Rupees, in lakhs (1 lakh = 100,000) |

## Deliberate data-quality issues (to practise cleaning)
